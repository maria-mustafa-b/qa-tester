# Security policy

## Supported versions

The latest release on the `main` branch receives security fixes during early development.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting
feature for this repository. Include the affected version, reproduction steps, impact and any safe
proof of concept.

## Authorized use

Preflight QA is intended only for systems the operator owns or is explicitly authorized to test.
The default scanner is non-destructive and does not grant permission to test third-party systems.
